# Mathematical Reference Cases

Version 0.1 · 18 November 2026 · Companion to [Spec 02](../specifications/02_MATHEMATICAL_ENGINEERING_SPECIFICATION.md) (§4, §12) · Tier S of the [benchmark plan](ENGINEERING_BENCHMARK_PLAN.md)

## Status and provenance of the numbers

- Values were computed for this document with 30-digit arbitrary-precision arithmetic (mpmath) from the formulas of Spec 02, and are shown to 13 significant digits. Units: mm, rad, mm².
- They are **author-computed, not yet independently reproduced**. Before any value is used as a qualification reference it must be recomputed by a second person with separate code (Spec 02 §12 rule 1). Until then each case has status *Draft*.
- Cases marked ✓ were cross-checked here by two different formulations.
- All radii are *reference-surface* radii (thickness and process assumptions excluded) unless stated. Parameter values are test inputs only; none is a recommended engineering value.

## 3. Metamorphic relations (apply to every family)

Rigid motion ⇒ congruent pattern · uniform scale $c$ ⇒ lengths × $c$, area × $c^2$ · mm ↔ inch input ⇒ identical geometry · seam shift ⇒ same invariants · mirror ⇒ mirrored pattern with reversed orientation flag · parameter limits (ECC-02 → CONE-01; BR → BR-05).

## 4. Seeded faults (verifier tests)

Wrong diameter reference (ID as OD) · wrong quadratic root (far side of header) · sign of $\psi$ reversed · pattern mirrored · weld gap dropped · kerf applied twice · mm/inch factor · seam sample duplicated or missing · triangulation result presented as exact. Each must be detected by the named check in Spec 02 §9; expected verdict FAIL (or INCONCLUSIVE where specified).
